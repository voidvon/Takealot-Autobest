如何获取 Authorization 凭证？（只需 20 秒）
  1. 在 Mac 上用 Chrome / Safari 打开并登录 sellers.takealot.com。
  2. 在页面空白处右键点击【检查】（或按 Option+Cmd+I）打开开发者工具，切换到 Network（网络） 选项卡。
  3. 点击页面任意操作（如点击 Existing Offers），在请求列表中找到包含 seller-api.takealot.com 的任意一条请求。
  4. 在 Request Headers（请求头） 中找到 authorization 项，将其后的完整字符串复制并粘贴到上方输入框保存即可。
