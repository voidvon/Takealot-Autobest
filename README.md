# Takealot 自动化智能助手 - 用户使用手册

欢迎使用 **Takealot 自动化控制中心**。本软件专为 Takealot 跨境电商卖家量身打造，提供 **全自动智能跟价抢 Buybox**、**防亏底价安全保护**、**多店铺统一管理**、**Excel 批量变体跟卖** 与 **实时竞价战报看板** 等核心功能。

---

## 🚀 快速开始

### 1. 启动软件
* **Windows 用户**：解压压缩包后，直接双击运行 **`Takealot.exe`** 即可。
  > 💡 *若 Windows Defender 提示“未知发布者”，请点击【更多信息】->【仍要运行】。*
* **macOS 用户**：解压压缩包后，直接双击打开 **`Takealot.app`** 即可。
  > 💡 *首次打开若提示“无法验证开发者”，请进入【系统设置】->【隐私与安全性】，在最下方点击【仍要打开】。*
* **服务器 / 纯后台模式（可选）**：如需在云服务器（Linux/Windows VPS）长期挂机，可通过命令行添加参数运行：
  ```bash
  ./Takealot.exe --server-only
  ```
  服务只监听本机 `http://127.0.0.1:8000`。远程使用请通过 SSH 本地端口转发，勿直接开放本地控制接口。

## 会员注册与登录

1. 启动后进入“会员账号”，注册用户名、密码及可选邮箱，再登录。
2. 在 GoCMS 后台“会员管理”创建标识为 `takealot-vip` 的会员组，给用户分配会员资格和有效期。
3. 客户端点击“刷新会员状态”，验证通过后即可使用业务功能。

开发环境默认 GoCMS 地址为 `http://127.0.0.1:18080`。正式部署必须指定 HTTPS：

```bash
./Takealot --gocms-url https://cms.example.com --member-group takealot-vip
```

也可设置 `TAKEALOT_GOCMS_URL` 和 `TAKEALOT_MEMBER_GROUP`；启动参数优先。
这些配置在本地进程启动时读取，不通过前端 API 修改。

- Cookie 保存在本地 Go 进程，登录成功后优先保存到系统凭据库；密码不落盘。
- 系统凭据库不可用时仅保留内存会话，界面会提示；重新启动可能需要重新登录。
- 携带有效 Cookie 再次登录会轮换会话，不额外占用 GoCMS 登录名额。
- 登录会话达到上限时，退出其他客户端或让管理员在 GoCMS 撤销旧会话。
- 每30秒在线复查会员状态；缓存超过45秒或会员到期即拒绝业务操作。
  启动调价/跟卖任务前会主动在线校验。
- 断网、服务不可用、账号禁用、会话撤销、VIP到期都会阻止后续受限操作；
  进行中的调价会停止，跟卖会在后续提交点停止。已发出的第三方请求无法撤回。
- 主动退出会停止调价并撤销 GoCMS 会话。退出时服务不可用则在本机锁定，
  不再自动恢复；可恢复网络后重试退出或重新登录。
- 客户端已移除旧离线激活码和机器码验证逻辑。旧 `.license` 文件和数据库中的旧授权字段不会再读取；
  不自动将旧授权转换成 VIP，请管理员按用户实际授权手动迁移。
- 这是单机工作区的会员准入控制。切换账号不会隔离或清除已保存的店铺数据。

## 📖 核心使用步骤

### 第一步：配置店铺与卖家授权
1. 打开浏览器登录 [Takealot 卖家后台 (Seller Portal)](https://sellers.takealot.com/)。
2. 在键盘上按 `F12` 打开浏览器开发者工具（或鼠标右键选择“检查”），切换到 **网络 (Network)** 标签页。
3. 在卖家后台任意点击一个页面（例如“Offers”），在网络请求列表中找到任意一条以 `seller-api.takealot.com` 开头的请求。
4. 查看该请求的 **请求标头 (Request Headers)**，找到并复制 **`authorization`** 字段的值（格式通常为 `Key 1234567890abcdef...`）。
5. 回到本软件界面，点击左侧菜单的 **【店铺管理】** 或 **【配置设置】**：
   - 将复制的 Token 粘贴到 **Authorization** 输入框。
   - 点击【测试连接状态】，显示“连接成功”即代表店铺已成功绑定。
   - *（支持绑定多个店铺，点击左侧店铺切换栏可快速新增并切换管理）*。

---

### 第二步：配置自动调价参数
在【参数配置】页面中，设置调价的基本规则：
* **轮询间隔（分钟）**：调价循环的周期，建议设置为 `3 ~ 5` 分钟。
* **降价步长 (R)**：当发现竞品价格低于我方时，我方每次下调的金额（例如设为 `1`，即比对手便宜 1 兰特）。
* **提价步长 (R)**：当竞品缺货、提价或我方独家在售时，系统每次回调价格的金额（赚取更多利润）。
* **最低底价保护**：系统严格遵守每件商品设置的底价，绝不会为了抢 Buybox 而亏本降价。
* **RRP 建议零售价比例 (%)**：自动计算展示的划线原价比例（例如 `120%`）。

设置完成后点击底部的 **【保存配置】**。

**同链接防竞争自动生效，无需设置**：同一系统内，最先处理商品的店铺会成为该商品的改价负责店铺，其他店铺遇到相同 TSIN 或 PLID 时自动跳过，并在日志中显示原因。归属会保存在本地数据库中，暂停、取消监控或重启不会转移归属；删除负责店铺后，其他店铺才可重新认领。不同商品仍可由不同店铺正常改价。此规则适用于自动调价，从更新后首次处理商品时开始认领。

---

### 第三步：商品监控与底价设置
1. 点击左侧菜单 **【监控商品】**。
2. 点击右上角 **【同步在售商品】**，系统将自动从店铺拉取当前所有已上架的商品。
3. 列表中会实时展示：
   - **当前售价** / **建议零售价 (RRP)** / **库存数量**
   - **竞品最低价** / **跟卖卖家数**
   - **当前状态**（处于优先 / 失去优先 / 独占在售）
4. **重要**：为需要开启调价的商品勾选 **【开启监控】**，并填入 **【最低售价 (Min Price)】** 与 **【最高限价 (Max Price)】**。
   > ⚠️ **安全防线**：最低底价是您的成本红线。当竞品价格低于您的最低底价时，系统会自动停止降价，防止恶性竞价导致亏本。
5. 勾选并设置完成后，点击右上角 **【保存监控商品】**。

---

### 第四步：一键开启全自动跟价
1. 返回左侧 **【控制看板】**。
2. 点击顶部的 **【启动跟价】** 按钮。
3. 系统将立即开始多协程自动化轮询：
   - 自动获取最新竞品数据。
   - 智能比价计算最佳 Buybox 价格。
   - 自动提交官方 API 更新售价。
   - 界面右上角会实时展示下次调价倒计时与实时战况日志。
4. 需要暂停时，随时点击 **【暂停】** 或 **【停止】** 即可。

---

### 第五步：Excel 批量跟卖（可选）
如果您需要批量跟卖爆款或录入新商品：
1. 打开软件目录下的 **`批量导入模板.xlsx`**（亦可在网页【批量跟卖】页面右上角直接点击下载）：
   - **第 1 列（Stock）**：跟卖上架的默认库存数量（例如 `10`）。
   - **第 2 列（Price）**：计划售卖价格 / 保底价格。
   - **第 3 列（URL/PLID/TSIN）**：Takealot 商品前台页面链接，或直接填写 PLID / TSIN。
2. 进入软件左侧的 **【批量跟卖】** 界面，将填写好的 Excel 文件直接**拖拽**进上传区域。
3. 系统将自动联网检索该商品的所有颜色、尺码变体：
   - 自动标出您尚未跟卖的款式变体。
   - 点击【一键跟卖】，系统将全自动上架未跟卖款式，并自动同步到调价监控列表中。

## ❓ 常见问题 (FAQ)

#### Q1：提示“授权失败 (401 / Unauthorized)”怎么办？
* **答**：Takealot 卖家后台的 Token 可能会随重新登录或过期而失效。请按《第一步》重新在卖家后台抓取最新的 `authorization`，粘贴到软件中保存并测试连接即可。

#### Q2：为什么有些商品明明被抢走了 Buybox，软件却没有降价？
* **答**：请优先检查该商品的 **最低底价 (Min Price)**：
  - 如果竞争对手的价格已经低于您设置的最低底价，系统的“防亏损保护机制”会坚决拒绝降价，避免产生亏损。
  - 请确认该商品是否已勾选【开启监控】并点击了【保存】。

#### Q3：软件运行时可以关闭电脑或断网吗？
* **答**：软件需要在开机且联网状态下才能与 Takealot 服务器通信调价。建议在日常办公电脑上保持软件最小化运行；或者部署在 24 小时运行的 Windows / Linux 云服务器上。

#### Q4：数据存储在哪里？更换电脑如何迁移？
* **答**：软件所有的店铺配置、商品底价和运行日志全部存储在同目录下的 **`takealot.db`** 数据库文件中。
  - 更换电脑时，只需将原来的 `takealot.db` 拷贝到新电脑的软件目录下，即可无缝还原所有数据与配置。

#### Q5：多店铺支持如何使用？
* **答**：在左下角点击【新增店铺】，输入店铺名称并填写对应店铺的 Authorization。调价引擎会同时为所有已激活的店铺并发进行独立比价与调价，各店铺参数互不干扰。
