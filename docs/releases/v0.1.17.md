本次新增主程序内的持久浏览器访问会话，并修复巡检、报价解析和价格提交中的异常处理。

### 新增与改进

- 顶部“引擎态势”前新增紧凑的“访问会话”入口；待验证时显示橙色状态和店铺数量。
- 卖家接口、商品接口在主窗口内左右并排显示，可独立重载；店铺选择使用 shadcn 下拉组件。
- 启用持久会话后，商品同步、抓价及价格提交复用该店铺的原生浏览器页面。关闭面板保留会话，按店铺和代理隔离资料。
- 遇到 Cloudflare 验证时暂停该店铺的巡检并打开验证面板。用户完成验证并点击“检查并恢复”后，从新一轮比价继续，避免提交旧目标价。
- 两个接口检查通过后，显示持续的绿色成功提示和“完成并关闭”按钮；面板由用户关闭。

### 修复

- 修复变体尺码、前台报价与可选评分字段的解析兼容问题，减少整页同步失败。
- 改进限流等待、请求取消、日志订阅和轮询倒计时；目录持续限流时降级处理，继续核对其他商品。
- 修复快捷改价失败时仍显示成功并更新本地缓存的问题；按 TSIN 改价时先解析真实卖家 Offer ID。
- 价格等写入遇到响应异常时不自动重放；手动停止或手动暂停的任务不会因验证恢复而自动启动。

### 使用与验证范围

下载 Windows x64 ZIP，解压后运行 `Takealot.exe`；包含批量导入模板、使用说明及集成验证记录。Windows 需要 Microsoft Edge WebView2 Runtime。启用或切换会话模式前，请先停止该店铺任务。

全项目 Go race 测试及前端生产构建通过，Windows x64 发布构建完成。macOS 主程序已完成 20 个商品的一轮巡检，以及保持原价的真实 PATCH 提交与回读。此前独立 macOS 原型完成过 60 分钟只读观察，该结果不等于 Windows 集成版的持续运行验证。

Windows WebView2 的验证页面、窗口交互和持续巡检尚未实机验证；真实价格变化及最终落价尚未验证。持久会话不能保证永久免验证，密集访问仍可能触发 429 限流。详细记录见压缩包中的 `docs/browser-session-integration.md`。
