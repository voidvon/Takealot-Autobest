# v0.2.0

## 文件夹独立与多开

- 店铺、商品、各规格价格保护、会员登录、界面设置、浏览器会话、日志及更新文件统一保存到程序旁的 `data/`。
- 不同文件夹中的软件可同时运行，自动分配本机端口；同一数据目录重复启动时会提示并退出，避免并发写入同一数据库。
- 关闭软件后复制整个软件文件夹（包含 `data/`），即可迁移到另一位置或另一台电脑。仅复制程序的新文件夹保持空店铺。
- macOS 的 `data/` 位于 `.app` 同级目录；自动更新保留数据目录和启动参数。目录不可写时明确报错，不回退到系统目录。

## 会员认证与旧数据迁移

- 会员认证改用 GoCMS Bearer Token，登录凭据保存在 `data/accounts/`，不向前端暴露，不保存密码。会员服务需 GoCMS v0.1.59 或更新版本。
- 首次升级且尚无新数据库时，从程序旁的旧 `takealot.db` 创建一致性快照，包含 WAL 中已提交的数据；原数据库和旧配置保留。
- 旧库迁移时会尝试读取原系统凭据库中的有效会员会话。旧 Cookie 中保存的会话凭据可作为 Bearer Token 验证，通过后可继续登录；凭据已过期、被撤销、原凭据库不可读或没有可迁移的旧库时，需重新登录。
- 新目录不会自动读取系统中的其他会员会话或导入不相关目录的配置。
- 复制文件夹会携带会员登录状态；副本使用同一个服务端会话，任一副本退出、改密或轮换该会话，可能使其他副本需要重新登录。需要独立会话时，在副本中重新登录，仍受会员服务的会话上限约束。

## 升级与使用

- 下载 Windows x64 ZIP，关闭旧程序后将新程序覆盖到原软件文件夹，再启动；请先备份原目录，保留原数据库及已有 `data/`。
- 迁移、复制或换电脑前，请关闭所有相关软件副本，避免复制到写入中的数据库和浏览器资料。
- 浏览器验证可能因系统、网络出口或平台策略变化而需要重做。旧 macOS WebKit 验证资料升级后需要重新验证；文件夹内持久浏览器要求 macOS 15.2+。Windows 仍需 WebView2 Runtime。
- 发布包仅包含程序、导入模板和使用文档，不包含数据库、店铺授权、会员 Token 或本地配置。
