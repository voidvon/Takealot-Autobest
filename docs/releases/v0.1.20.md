# v0.1.20

## 实际售价与 RRP 独立

- 自动竞价、批量跟卖、商品编辑和订单快捷改价不再按比例生成或提交参考划线价（RRP），保留平台已有 RRP。
- 移除店铺设置中的 RRP 浮动比例、底价折算倍数，以及商品编辑中的 RRP 输入和“随售价自动折算”选项。
- 修改实际售价会保留已保存的底价、封顶价与监控勾选状态，不再联动重算底价。

## 价格保护配置

- 底价与封顶价统一在自动竞价列表配置；多规格商品继续通过“配置规格价格”弹窗分别设置。
- 批量设置底价改为直接填写整数金额，支持只填空白或统一设置；发现底价高于已有封顶价时拒绝应用。
- 普通商品编辑和订单快捷改价接口按所属店铺、具体 TSIN 校验已保存的价格范围，拒绝低于底价或高于封顶价的售价。
- 手动改价弹窗增加范围错误提示；拒绝旧客户端显式提交 RRP，以及通过附加字段覆盖售价。

## 升级说明

- 已有店铺、商品底价、封顶价及平台 RRP 保留；旧比例字段仅为数据兼容保留，不再参与价格计算。
- 升级后请先核对各规格已保存的底价和封顶价；历史上被错误折算的底价需要按实际成本重新确认。
- 本地底价约束软件提交的报价，平台促销等规则仍可能影响买家成交价，请在 Takealot 后台核对相关活动。
- 下载 Windows x64 ZIP，解压后运行 `Takealot.exe`。压缩包只包含程序、导入模板与使用文档，不包含数据库、店铺授权或本地配置。

## 验证

- Go 全量测试及竞态检测、前端构建、macOS arm64 / Windows amd64 Wails 构建通过。
- 隔离演示数据验证：底价 R210 时提交售价 R120 被拦截；改为 R250 成功，底价 R210、封顶价 R400 保持不变。
- 模拟接口回归覆盖 RRP 不提交、缓存 RRP 保留、自动跟价、跟卖创建与手动价格范围校验。
- 本轮未修改真实店铺售价；Windows 实机运行及真实平台价格传播仍需现场验证。
