# v0.2.1

修复多规格商品在前台有报价却被跳过跟价的问题，并减少会员校验和重复异常反馈。

## 修复与调整

- 会员状态启动时联网校验，此后每 24 小时自动复查一次；已知会员到期时间仍在本地判断。登录、手动刷新和手动启动任务仍会联网验证。
- 会员服务临时不可用时，已运行的巡检显示“等待会员验证”并暂停提交；验证恢复后从新一轮继续。手动暂停、停止和网页验证状态仍保留；确认会员到期或资格失效时停止任务。
- 修复颜色、尺码的单维查询提前耗尽 24 次额度，导致真实存在的 TSIN 无法定位。现在逐层选择规格，同一商品组每轮共享 96 次实际规格请求预算，缓存读取不重复计数。
- 只记住已确认的 TSIN 与规格参数对应关系，每轮重新读取报价；规格参数变化后重新定位，避免使用过期价格。
- 修复错误文本中 TSIN 含有 `403` 时被误报为 Cloudflare 拦截的问题，新增“规格定位失败”分类。真实 HTTP 403 仍会报告，平台访问限制仍可能需要网页验证。
- 同店铺、同商品组、同类异常每 24 小时最多自动反馈一条，去重记录保存在 `data/logs/feedback-rate-limit.json`，重启后继续生效；逐规格详情保留在客户端日志。

## 升级

下载 Windows x64 ZIP，关闭旧程序后将新程序覆盖到原软件文件夹，保留已有 `data/`。发布包仅包含程序、导入模板和 README，不包含数据库、会员凭据或店铺配置。

## 验证

- Go 全量竞态测试通过；前端、macOS arm64 及 Windows amd64 生产构建通过。
- 真实响应回放覆盖多规格、共享请求预算、规格映射失效、错误分类及反馈重启去重。
- 对反馈中的两件商品进行只读验证：成功定位 Nude / 34B（2 条报价）及 Grey / 44B（1 条报价）；下一轮各用一次新的规格读取获取报价。
- Windows 完成交叉编译及发布包检查，尚未进行 Windows 实机验证。本次验证没有修改真实店铺价格。
