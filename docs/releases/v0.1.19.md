# v0.1.19

## 多规格独立价格保护

- 自动竞价列表中的多规格商品显示“配置规格价格”按钮，可在弹窗中按 TSIN 分别编辑防亏底价和封顶价；单规格商品保留直接输入。
- 保存规格价格不改变当前售价或监控勾选状态，同步商品不再覆盖已保存的底价。
- 自动跟价按具体规格重新读取价格范围；已确认平台售价低于底价时优先恢复到底价，缺少有效底价或限价冲突时跳过并提示。
- 收紧规格与卖家身份匹配，清理同一规格的旧重复监控，避免混用其他规格或店铺的价格保护配置。

## 导入与批量跟卖

- Excel 支持可选的 TSIN、初始售价和封顶价，旧三列表格仍可导入。
- 上架前解析并核对各规格价格，只提交勾选的规格；成功后分别保存底价并加入本地商品列表和监控。
- 随包导入模板与应用下载模板同步更新。库存列表示计划备货量，使用 Takealot 平台仓仍需完成入仓后才有实际可售库存。

## 首次启动与店铺管理

- 全新安装保持空店铺，不再自动创建 Default，也不再自动将邻近的旧配置或 GJDATA 导入为店铺或监控。
- 无店铺时显示添加入口并禁用巡检；删除最后一个店铺后重启仍保持为空。
- 无效店铺 ID 不再静默切换到其他店铺；局部修改店铺设置时保留未提交的授权和其他配置。
- 移除历史记录中硬编码的店铺名称，以及空发货单、预约列表自动生成的演示数据。

## 升级说明

- 已有数据库和店铺记录继续保留，不会自动删除旧 Default 或其他已有店铺。店铺记录保存在本地，会员登录不会从云端下发店铺列表。
- 升级后启动巡检前，请核对各规格底价与封顶价。平台售价已低于保存底价的商品会优先恢复到底价。
- 下载 Windows x64 ZIP，解压后运行 `Takealot.exe`。发行包不包含数据库、授权凭据或本地配置。

## 验证

- Go 完整测试、相关 race 测试、前端构建、macOS arm64 / Windows amd64 构建通过；空店铺界面已验证。
- 导入、规格上架、独立限价、同步和自动跟价已通过模拟接口集成测试。本轮未创建真实商品或提交真实改价，Windows 实机运行仍需现场验证。
